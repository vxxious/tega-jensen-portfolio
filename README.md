# Tega Jensen Portfolio

A one-page professional portfolio for Tega Jensen, focused on AI evaluation, content quality, data annotation, research, and quality assurance.

**Live site:** [tega-jensen-portfolio.vercel.app](https://tega-jensen-portfolio.vercel.app/)

## Tech stack

- React 19
- Vite 7
- TypeScript
- Tailwind CSS 4

## Local development

```bash
npm install
npm run dev
```

## Validation and build

```bash
npm run lint
npm run build
npm run preview
```

## Deployment

The production site is deployed to Vercel from the `main` branch. Vite outputs the production build to `dist/`.
